Machine learning project for predicting house prices using Python and Scikit-learn.

# House Price Prediction

This project predicts house prices using Machine Learning techniques in Python.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Outlier Handling
4. Feature Engineering
5. Data Encoding
6. Model Building
7. Model Evaluation

## Models Used
- Linear Regression
- Random Forest Regressor

## Evaluation Metrics
- R2 Score
- Mean Absolute Error
- Mean Squared Error

## Key Features
- Performed EDA using visualizations
- Handled missing values and outliers
- Applied feature engineering techniques
- Compared multiple ML models

## Results
The Random Forest model achieved better prediction performance compared to Linear Regression.
